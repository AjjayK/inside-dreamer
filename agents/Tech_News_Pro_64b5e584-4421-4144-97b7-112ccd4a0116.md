# Agent: Tech News Pro

**ID:** 64b5e584-4421-4144-97b7-112ccd4a0116

## Description

# OVERVIEW
Techmeme Reader is a complete app agent that fetches and presents the latest Techmeme technology news stories. Built with a Gmail-like interface, it provides efficient keyboard navigation, story selection, archiving capabilities, and AI-generated summaries with full user customization to help users stay current with tech news.

# KEY FEATURES

## RSS Feed Integration
- Successfully fetches stories from Techmeme's RSS feed at https://www.techmeme.com/feed.xml
- Auto-fetches stories on app startup with configurable limits (default: 50 stories)
- Manual refresh capability with refresh button (R key removed)
- Automatic 7-day story cleanup to prevent database bloat

## Enhanced Gmail-Style Interface & Navigation
- **Keyboard Shortcuts:**
  - J/K, N/P, or ↑/↓ arrows: Navigate next/previous story
  - X: Toggle story selection (shows checkboxes)
  - E: Archive current story or all selected stories
  - Enter: Expand/collapse story summary
  - Escape: Unselect all stories OR close settings modal
- Visual story navigation indicator shows current position (e.g., "Story 3 of 15")
- Auto-scroll keeps current story centered on screen
- Ring highlight around currently selected story
- Smart keyboard handling - shortcuts disabled when typing in settings

## Story Display & Interaction
- Stories displayed in uniform boxes with 1px gray borders, rounded corners, and card backgrounds
- Headlines converted to sentence case and displayed in bold
- Clicking headline opens original article in new tab (extracts real source URL from Techmeme content)
- **Enhanced Image Display:** 2x wider thumbnails (96px wide) for better visual prominence
- **Repositioned Selection:** Checkboxes moved to bottom-left corner for better layout
- Responsive image hiding on narrow screens (mobile) for optimal space usage
- Timestamp display showing when story was fetched
- Archive button on each story with hover effects

## AI-Powered Summaries with Full Customization
- **Default LLM Summary Generation:**
  - 5-bullet point objective summaries that avoid repeating headline information
  - Progressive disclosure: first line visible by default, click to expand/collapse full summary
  - "Summarizing..." loading state with spinner for responsive UX
  - Summaries cached to avoid regenerating for the same story

- **Custom Prompt System:**
  - Full user control over summarization prompts via Settings panel
  - Template variable support: `${story.title}` and `${story.description}` placeholders
  - Real-time prompt editing with proper state management
  - Two save options: "Save Only" or "Save & Re-summarize All"
  - Automatic re-summarization of all unread stories when prompt changes

- **Default Prompt Template:**
  ```
  Create an objective, factual summary of this news story in exactly 5 bullet points. Focus on key facts and details that aren't already obvious from the headline. Do not repeat information from the headline.

  Title: ${story.title}

  ```

# AI FEATURES

## Advanced LLM Summary Generation
- Uses Claude LLM via SDK for high-quality, factual summaries
- **Customizable Prompt System:** Users can modify summarization behavior
- Template variable replacement: `${story.title}` and `${story.description}`
- Structured prompt engineering ensures consistent output format
- Intelligent content filtering to avoid headline redundancy
- Summary caching prevents unnecessary API calls for same content
- **Multi-Filter Batching:** Summarization and ALL filter evaluations combined in a single LLM call per story for maximum efficiency

## Smart Prompt Management
- Real-time prompt editing with proper state synchronization
- Bulk re-summarization when prompts are updated
- Template validation and placeholder replacement
- Persistent storage of custom prompts across sessions

## Enhanced State Management & Filtering
- Tracks which stories have summaries to avoid regeneration
- Progressive enhancement - summaries generated on-demand rather than blocking initial load
- Preserves summary data and custom prompts across app sessions through KV store persistence
- Intelligent re-summarization when prompt templates change
- **All-Filter Pre-Application:** During story fetch, ALL filters are evaluated simultaneously and results cached per story
- **Instant Filter Switching:** No LLM calls needed when switching between filters - results restored from cache
- Prevents expensive batch filtering that could disable the app due to high LLM usage

## Smart Briefing (Experimental)
Personalized narrative briefings that synthesize tech news with the user's personal context.

- **What It Does:** Generates a contextual narrative summary of tech stories since the last scheduled update, synthesized by Sidekick using the user's personal context (work focus, interests, projects, calendar, and goals)
- **Output Format:** Both text (with clickable story links) and audio narration (5-8 minutes)
- **Tone:** Casual, addresses user by name, assumes deep technical knowledge, focuses on "what happened" and calls out why each story is relevant to the user specifically
- **Delivery:** Posted to the user's feed at each scheduled audio update time alongside regular audio summaries
- **Filtering:** Respects whatever topic/category filters the user has selected for their regular audio summaries
- **Settings:** Experimental toggle in Settings to enable/disable (off by default), only available when "Audio Summary in my Feed" is enabled

### How Smart Briefing Works
1. At each scheduled audio update time, if Smart Briefing is enabled, a Sidekick task is created
2. Sidekick receives all stories since the last update (filtered if applicable) plus user personal context from memory
3. Sidekick writes a narrative briefing connecting tech news to the user's context
4. The briefing is converted to speech via TTS
5. Both text (with links) and audio are posted to the user's feed

# TECHNICAL IMPLEMENTATION

## Architecture
- **Frontend:** React 19 with TypeScript, responsive design using Tailwind CSS
- **Backend:** Bun runtime with typed server functions for all data operations
- **State Management:** Server-side KV store with reactive frontend hooks and optimistic updates
- **RSS Processing:** Dedicated RSS-explorer tool for reliable feed parsing
- **AI Integration:** Built-in SDK LLM calls with structured response schemas and custom prompts

## Server Functions (Exported for Agent Integration)
- `getStories`: Reactive story retrieval with dependency tracking
- `fetchStories`: RSS feed fetching with error handling and auto-summarization
- `archiveStory`: Individual story archiving
- `archiveSelectedStories`: Bulk archiving operations
- `toggleStorySelection`: Selection state management with optimistic updates
- `generateStorySummary`: On-demand AI summary generation with custom prompts
- `unselectAllStories`: Bulk deselection functionality
- `getSummaryPrompt`: Retrieve current custom summarization prompt
- `setSummaryPrompt`: Update prompt and optionally re-summarize stories
- `resetAllData`: Complete data reset functionality
- `getSmartBriefingConfig`: Retrieve Smart Briefing configuration
- `setSmartBriefingConfig`: Enable/disable Smart Briefing
- `generateSmartBriefing`: Trigger Smart Briefing generation via Sidekick task
- `receiveSmartBriefing`: Callback endpoint for Sidekick task to deliver completed briefing (exported for Sidekick access)

## Data Flow
1. RSS feed fetched from https://www.techmeme.com/feed.xml
2. Stories parsed and processed (title case conversion, URL extraction)
3. Auto-summarization with current user prompt (default or custom)
4. Data stored in KV store with proper typing and validation
5. Frontend reactively displays stories with optimistic updates
6. Custom prompts managed through settings with real-time editing
7. Summaries regenerated when prompt templates are updated

## Advanced Features Implementation
- **Responsive Image Display:** CSS breakpoint detection for mobile optimization
- **Enhanced Keyboard Navigation:** Arrow key support with smart input field detection
- **Modal System:** Overlay-based settings with backdrop and focus management
- **Template Engine:** Regex-based variable replacement for custom prompts
- **State Synchronization:** Proper initialization handling to prevent edit conflicts
- **Efficient Filter Processing:** ALL filters are applied during initial story fetch in a single LLM call per story, eliminating expensive re-filtering when switching between filters

## Error Handling & Reliability
- Comprehensive error handling for RSS feed failures
- Graceful degradation when external services unavailable
- User-friendly error messages displayed in status bar
- Retry mechanisms for transient failures
- Input validation for custom prompt templates
- Safe template variable replacement with fallback handling
- Prevents infinite render loops in React hooks with proper dependency management
